# Scopework application icon

Generated with the built-in image generation tool, then converted without changing the design into PNG and a multi-resolution Windows ICO using `build-icon.ps1` (System.Drawing). The ICO contains 16, 24, 32, 48, 64, 128 and 256 pixel frames. `scopework-source.png` is the original output; `scopework.png` and `scopework.ico` are the application assets. Alpha is preserved.

Prompt:

> Use case: logo-brand. Create the final Windows desktop application icon for Scopework, a serious research workbench that organizes understanding into functions, chunks and systems. One centered, distinctive symbol: three stacked, offset deep-teal panels forming a compact stepped S-like silhouette, with a bright mint focus aperture cut into the central panel. Strong readable silhouette at 16 to 48 pixels. Subtle dimensional polished enamel, restrained highlights, precise crisp edges, premium professional desktop utility rather than a game icon. The mark fills about 84% of a square canvas. Transparent outside the mark, no enclosing app tile, no text, no letters, no mockup, no extra elements, no drop shadow beyond the silhouette. Output one square icon asset.

The icon is embedded into both Windows executables and used by the dashboard title bar, window/taskbar, installer, Start menu and installed-app entry.
