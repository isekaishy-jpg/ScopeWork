# Scopework application icon

Generated with the built-in image generation tool, then converted without changing the design into PNG and a multi-resolution Windows ICO using `build-icon.ps1` (System.Drawing). The ICO contains 16, 24, 32, 48, 64, 128 and 256 pixel frames. `scopework-source.png` is the original output; `scopework.png` and `scopework.ico` are the application assets; `scopework-16.png` is used at native size in the custom title bar. Alpha is preserved.

Prompt:

> Use case: logo-brand. Design a crisp, restrained professional Windows application icon for Scopework, a research workbench. Completely new concept: a compact flat dark midnight-navy rounded-square tile, with four strong off-white right-angle focus brackets framing two short cyan horizontal evidence bars. The negative space is generous and the silhouette very simple. Front-facing flat 2D vector-like geometry, optically balanced, perfectly uniform solid fills, hard clean edges. Every stroke thick enough to remain unmistakable at 16 pixels; no fine details. Tile nearly fills the square canvas with a small consistent transparent outer margin. No letter S, no stacked slabs, no 3D, no lighting, no glass, no bevel, no shadows, no gradient, no blur, no noise, no text, no mockup, no surrounding scene. One final production icon, not a sheet of alternatives.

The icon is embedded into both Windows executables and used by the dashboard title bar, window/taskbar, installer, Start menu and installed-app entry.
