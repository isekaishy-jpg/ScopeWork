# Agent complaints

File complaints about the research dashboard in this folder. Use one Markdown file per narrow issue, named `YYYY-MM-DD-agent-short-topic.md` (add a suffix if the name already exists).

Briefly describe what you were doing, what bothered you, and how it affected the task. Include a concrete example when useful. A suggested improvement is optional.

Keep each report focused on one app issue. Filing the report is the entire process.
